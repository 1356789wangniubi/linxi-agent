# 鳞析 · 公开使用说明

## 演示入口

演示地址和访问码由维护者私下提供，公开仓库不保存有效凭据。旧版文档曾公开的访问码应停用并重新生成；当前文件的删除不能清除 Git 历史中的副本。

## 三项功能

1. 引导：解释图像测量、测线布置、侧线原理和仿真思路，结合项目资料及十篇论文回答问题。
2. 检验：上传仿真 CSV 或粘贴数据，与参考结果比较，显示误差指标和图表，提供排查思路。
3. 坐标查询：输入 x、y、t，查询鱼体404探针对应的压强、速度和时间曲线。坐标结果来自参考数据插值。

## 启动与密钥

- 本机可使用 chat.bat；需要智谱服务时使用 chat_zhipu.bat。
- 智谱 API 密钥仅在服务端配置；secrets/、环境文件、访问码文件和运行日志不应提交 GitHub。
- 公网服务需要独立随机访问码及 HTTPS。新版服务要求配置的访问码至少16字符。旧访问码请由维护者更换。
- 通用问答及工具规划可能向智谱发送问题或聊天上下文，不要在聊天中输入私密资料。表格校验由本地工具处理。

## 本次源码更新

智谱模型配置为 glm-5.3-flash（按用户指定填写，尚未完成官方可用性核验和真实 API 测试）。旧服务需停止后重新启动。

服务端增加共享调用限流（每分钟6次、每小时60次、每日200次），每次执行1个任务，限制聊天输入，并隐藏内部异常细节。额度是单进程内存计数，重启后重置，不能替代智谱控制台的账单额度。

该版本适合受邀演示，共享访问码不提供用户之间的文件隔离。正式多用户部署需添加独立登录、用户数据隔离、持久化配额和 HTTPS 网关。

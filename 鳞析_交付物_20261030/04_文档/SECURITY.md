# 密钥与公网运行

智谱密钥由服务端从环境变量或 Windows DPAPI 文件 `secrets/zhipu.key` 读取。前端不接收密钥。通用问答和工具规划可能向智谱发送问题或聊天上下文。

## 本次修改

- 模型标识设为 `glm-5.3-flash`，真实 API 可用性尚未核验。
- 删除公开启动脚本里的固定访问码；下次启动时使用独立随机码。已存在的短码会被拒绝，由维护者更换。
- 公网入口只转发自己新建且验证过认证的本机服务，不会转发已有的未认证服务；隧道退出时清理自己启动的服务。
- 非本机监听必须启用至少16字符访问码；公网仍应使用 HTTPS。
- POST 接口共享限流：每分钟6次、每小时60次、24小时200次。额度按进程计数，重启后重置。每次执行1个任务，最多8个连接线程。
- 限制请求体、聊天消息、上下文和图片像素；每次模型生成最多1024个 token。
- 保护输出目录边界，阻止下载凭据和日志文件，隐藏内部异常与索引源路径。
- `.gitignore` 和打包脚本排除密钥、环境文件、隧道状态、运行日志和用户运行产物。

## 运行边界

共享演示访问码不提供不同用户之间的数据隔离。调用限流不能替代智谱控制台的账单额度。源码公开后，接口地址和代码可被查看；真正需要保密的是服务端密钥。正式多用户部署需要独立登录、用户数据隔离和持久化配额。

旧版公开过的访问码已经视为泄露。当前文件及源码包已清理，Git 历史未重写。旧服务必须停用并更换访问码；如 API 密钥也曾公开，应由维护者在智谱控制台撤销并重建。

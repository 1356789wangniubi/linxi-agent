# 鳞析 · 鱼类侧线仿真助手

## 启动

双击 `chat.bat`（仅本机），或：

```powershell
python -m fishflow.chat_server
```

浏览器会自动打开 `http://127.0.0.1:8765/`。

### 用智谱 GLM-4-Flash

双击 **`chat_zhipu.bat`**。

- 需要先用 `python -m fishflow.secret_setup` 录入 key；
- key 用 Windows DPAPI 加密存在 `secrets/zhipu.key`，源码/批处理里没有明文；
- 只有未知的通用问题会走智谱；侧线知识、工具数值仍走本地；
- 详见 [SECURITY.md](SECURITY.md)。

### 给同网用户用

双击 **`chat_lan.bat`**，或：

```powershell
python -m fishflow.chat_server --host 0.0.0.0
```

黑窗口会打印一个局域网地址，例如：

```text
http://10.172.243.19:8765/
```

同 Wi-Fi / 校园网的手机、电脑可以直接打开。
首次可能需要在 Windows 防火墙里允许 Python；只建议在可信网络使用（没有登录认证）。

- 本地运行，不需要联网；
- 左边是示例问题，点一下就能问；
- 回答带“参考”，不确定会说“不确定”。

## 直接画图

说：

> 给我看一个侧线信号

它会生成 `outputs/ll_dipole.png`：

- 左图：2 Hz 振动偶极子的压力场 + 16 传感器阵列；
- 右图：4 个传感器上的压力时序；
- 用的是解析偶极子，不是 CFD，适合讲清“源—传播—阵列信号”。

说：

> 我的 404 探针能当侧线用吗？

它会生成 `outputs/ll_from_probes.png`：把 404 个表面探针降采样成 16 点阵列。

## 引导式仿真（给一条鱼）

说：

> 我给你一条鱼，帮我做侧线仿真

会弹出一张参数卡：

| 参数 | 含义 |
|---|---|
| 预设 | 斑马鱼 / 鲤鱼 / 金枪鱼 / 自定义 |
| 体长 L、体高 H | 鱼体几何 |
| 流速 U | 均匀来流 |
| 传感器数 | 体侧阵列，双侧布置 |
| 源 x/L、y/L | 振动偶极子相对位置 |
| 频率 f、噪声 | 源频率与测量噪声 |
| 鱼图（可选） | 上传 PNG/白底 JPG，按轮廓比例估体高 |

点“开始仿真”，输出：

- 四联图：压力场 + 阵列热图 + 代表点时序 + 源定位；
- 指标：SNR、幅值-距离拟合 R²、源定位误差（体长归一化）；
- JSON 下载。

> 这是二维解析模型（均匀流 + 偶极子），用来跑通“几何→阵列→信号→解码”闭环，不是 CFD。
> 图片只用于估 H/L 比例/轮廓；绝对尺寸来自你输入的体长。复杂背景会分割失败，优先用 PNG 透明底或白底。

## 三类工具（LLM 负责路由）

用户一句话 → LLM/规则判断意图 → 调工具 → LLM 整理结果：

| 分支 | 例子 | 工具 |
|---|---|---|
| 查询解释 | 这个数据怎么来的？这个峰值是什么？ | meta / origin / peak |
| 计算分析 | 画 t=2s 压力云图；算侧线感知的涡位置；画多模态涡量场；画物理模型真涡量场；拟合 Lighthill | pressure_cloud / vortex / vorticity / physical_vorticity / lighthill |
| 控制仿真 | 给定来流速度 0.3 m/s，预测侧线输出 | forward |

没配 LLM 时用规则路由；配了 `FISHFLOW_LLM_URL` 后，LLM 只负责“选工具 + 写总结”，
数字和图仍由 Python 工具产出。

## 十篇论文与思考引导

- 问“十篇论文是哪十篇？”→ 给阅读顺序和每篇的问题/方法/结论/边界；

## 检验你的仿真

在聊天里说“**检验我的仿真**”，或点左边栏的“**仿真全过程检验**”，上传 CSV。

**没有 CSV 也可以**：直接在聊天里贴数据，或把数据粘到检验表单的文本框。每行一组：

```text
t=0.2, probe=17, p=-0.03, ux=0.45, uy=0.18
t=0.21, probe=17, p=-0.02, ux=0.44, uy=0.17
```

智能体会先把它写成 CSV（下载链接会返回），再直接检验。说“帮我生成一份示例数据”会生成带**示例**标记的 CSV，只用于测试流程。

CSV 只要满足：

```text
time,probe,p,ux,uy
```

或坐标表：

```text
time,x,y,p,ux,uy
```

返回：

- A/B/RMSE/偏差/均值比；
- 四联图：parity、指标、代表探针时序、几何；
- 明确提示单位/列映射/时间窗/探针覆盖问题。

模板：`examples/user_simulation_template.csv`（网页表单里也有“下载参考模板”按钮）。

正确数据通常有三种来源：

- **默认用系统内置参考**：只传你自己的结果即可，不需要额外找正确文件；
- **老师/课题组导出的正确表**：需要数据拥有者提供，至少含 `time, probe 或 x/y, p, ux, uy`；
- **系统参考模板**：只有 3 探针 × 3 时刻，用于格式/自测，不是全量真值。

全量老师数据和原始表不公开下载，需要时向数据拥有者申请。

## 数据不对时：先给可能原因，不替你下结论

校验结果会附带“**可能哪里错了（按可能性排序）**”，最多 6 条。每条包含：

- 证据：实际算出来的均值比/相关/时移/探针偏移；
- 自查：先看什么；
- 修：确认后怎么改。

常见假设：

- 量纲/归一化：Pa vs p/(ρU²)、峰峰值 vs 幅值；
- 符号：表压/绝压、上下游方向；
- ux/uy 列接反；
- 时间起点/采样相位偏移；
- 探针编号 0/1 起始或上下表面顺序反了；
- 缺启动段或时间窗太短；
- 坐标单位 cm/mm 或 x/y 互换。

如果数据完全落在参考范围外，会先给“数据画像”，再给时间/probe/列名三条自查。

## 坐标查压强/速度

打开 **http://127.0.0.1:8765/point**：

- 页面画的是**整条鱼的表面轮廓**，上面有 **404 个探针**；
- 点击任意探针，右侧显示该点的 `p / ux / uy`、坐标和时间曲线；
- 拖动时间轴可以换帧，曲线会跟着更新；
- x 轴固定为 **1.9–3.1 m**，横向拉长，鱼体不会被压扁；
- 底部仍保留 `x/y/t` 坐标查询：最近 3 个探针反距离加权。

注意：这是**查参考索引**，不是重新做 CFD；点离鱼体太远时只是近似。

## 知识边界

- 侧线部分是基于综述/文献的**概念性知识**，不是某个具体实验的标定；
- 偶极子图是**最小解析模型**，没有黏性、涡、鱼体边界；
- 404 探针数据是二维无黏势流，可以验证“阵列+解码”流程，但不能声称真实侧线精度；
- 不编数字、不编用户日志。

## 可选：接通用大模型（让 LLM 做路由/总结）

默认用规则路由 + 模板总结。配置 OpenAI 兼容端点后，LLM 负责：
1. 判断走哪个分支/工具；
2. 把工具结果整理成自然语言，并提醒误差/追问参数。

```powershell
$env:FISHFLOW_LLM_URL="http://127.0.0.1:11434/v1/chat/completions"
$env:FISHFLOW_LLM_MODEL="qwen2.5:7b-instruct"
$env:FISHFLOW_LLM_KEY="ollama"
python -m fishflow.chat_server
```

数字和图仍然只来自 Python 工具，LLM 不碰原始数据。

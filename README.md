# 鳞析 · 鱼类侧线仿真助手

提供测量和仿真引导、仿真表格对照检验，以及404探针的压强和速度坐标查询。

## 使用

1. 下载仓库后，将 `鳞析_交付物_20261030/03_源码/源码_智能体.zip` 解压在同一目录，得到 `源码_智能体` 文件夹。
2. 进入该文件夹，安装 `requirements.txt` 中的 Python 依赖；默认 DMD 索引和老师原始数据需由维护者自行准备，未公开发布。
3. 智谱密钥仅在本地使用 `python -m fishflow.secret_setup` 配置。模型配置为 `glm-5.3-flash`，真实 API 可用性尚未测试。
4. 启动 `chat_zhipu.bat` 使用本机聊天；需要受邀公网演示时使用 `开始公开.bat`，访问码只私下分享。

安全修改及测试范围见 [SECURITY.md](鳞析_交付物_20261030/04_文档/SECURITY.md)。旧文档中的访问码应停用；本次未重写 Git 历史。当前服务适合共享受邀演示，正式多用户部署还需独立登录及用户数据隔离。
